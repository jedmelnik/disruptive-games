# Disruptive Games

A studio site for [Disruptive Games](https://www.disruptivegames.com/), rebuilt as a Next.js app. The wordmark, game art, and facts come from the live site. Wreck Runners frames come from the Steam listing the studio links.

## Run locally

```bash
cd /workspace/worktrees/disruptive-games
npm install
npm run dev -- --port 43117
```

Open [http://127.0.0.1:43117](http://127.0.0.1:43117).

## Stack

Next.js App Router, TypeScript, Tailwind CSS, shadcn/ui.
